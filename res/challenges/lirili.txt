PROMPT:
Which keyword lets a class adopt an interface contract?
CODE:
interface Tickable {
    void tick();
}

}
ANSWER: implements
EXPLANATION: A class uses 'implements' to fulfill an interface contract.
HINT: Classes use 'extends' for a superclass, and a different keyword for an interface.
