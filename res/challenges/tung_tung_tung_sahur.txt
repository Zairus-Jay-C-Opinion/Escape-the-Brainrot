ID: TTS-03
TYPE: PREDICT
DIFFICULTY: MEDIUM
PROMPT:
[Polymorphism] Dynamic method dispatch. What prints to standard output?
CODE:
class Monster {
    void roar() { System.out.print("Roar "); }
}
class Sahur extends Monster {
    void roar() { System.out.print("Tung "); }
}
public class Main {
    public static void main(String[] args) {
        Monster m = new Sahur();
        m.roar();
        System.out.print("Tung!");
    }
}
ANSWER: Tung Tung!
HINT: At runtime, Java executes the overridden method in Sahur because the actual object is an instance of Sahur.

ID: TTS-06
TYPE: PREDICT
DIFFICULTY: HARD
PROMPT:
[All 4 Pillars Synthesis] Polymorphism with constructors and abstract classes. What does this program print?
CODE:
abstract class Entity {
    Entity() { System.out.print("Tung"); }
    abstract void hit();
}
class Trunk extends Entity {
    Trunk() { System.out.print("-Tung"); }
    void hit() { System.out.print("-Sahur!"); }
}
public class Main {
    public static void main(String[] args) {
        Entity e = new Trunk();
        e.hit();
    }
}
ANSWER: Tung-Tung-Sahur!
HINT: Object construction calls the superclass constructor first, followed by the subclass constructor, then the overridden method.

ID: TTS-07
TYPE: PREDICT
DIFFICULTY: HARD
PROMPT:
[Polymorphism & Static Hiding] What is printed to standard output?
CODE:
class Bark {
    static void crack() { System.out.print("B"); }
    void splinter() { System.out.print("1"); }
}
class Oak extends Bark {
    static void crack() { System.out.print("O"); }
    void splinter() { System.out.print("2"); }
}
public class Main {
    public static void main(String[] args) {
        Bark b = new Oak();
        b.crack();
        b.splinter();
    }
}
ANSWER: B2
HINT: Static methods are hidden (bound at compile time to reference type Bark), while instance methods are overridden (polymorphic at runtime).
