ID: INH-01
TYPE: FILL_BLANK
DIFFICULTY: EASY
PROMPT:
Scenario: To create a class hierarchy, you want Class Airplane to inherit from Vehicle. 
What keyword belongs in the blank?
CODE:
class Vehicle {}

class Airplane ___ Vehicle {
    int wings = 2;
}
ANSWER: extends
HINT: Look for the Java keyword used to declare a class as a subclass of another.

ID: INH-02
TYPE: PREDICT
DIFFICULTY: EASY
PROMPT:
What does this program print to standard output?
CODE:
class Plane {
    void fly() { System.out.print("Vroom"); }
}
class Bomber extends Plane {
    void fly() { 
        super.fly(); 
        System.out.print(" Boom!"); 
    }
}
public class Main {
    public static void main(String[] args) {
        Bomber b = new Bomber();
        b.fly();
    }
}
ANSWER: Vroom Boom!
HINT: Remember that calling super.fly() runs the method from the parent class first.

ID: INH-05
TYPE: PREDICT
DIFFICULTY: HARD
PROMPT:
What will this code print to the screen? Use careful tracking of polymorphism!
CODE:
class Creature {
    Creature() { System.out.print("C"); }
    void attack() { System.out.print(" Strike"); }
}
class Croc extends Creature {
    Croc() { System.out.print("R"); }
    void attack() { 
        super.attack(); 
        System.out.print(" Bite!"); 
    }
}
public class Main {
    public static void main(String[] args) {
        Creature target = new Croc();
        target.attack();
    }
}
ANSWER: CR Strike Bite!
HINT: Creation of an object prints from the superclass constructor first, followed by the subclass constructor. Then analyze the method calls.
