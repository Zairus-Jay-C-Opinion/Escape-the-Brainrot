## Instructions for Running the Program
You need **JDK 21** installed (`java -version` should say 21).

**Mac / Linux**
```
./run.sh
```
(If it says permission denied, run `chmod +x run.sh` once.)

**Windows**
```
run.bat
```

Both scripts compile `src/` into `bin/`, copy `res/` into `bin/`, and start the game. You can run them from any folder; they find the project by themselves.
